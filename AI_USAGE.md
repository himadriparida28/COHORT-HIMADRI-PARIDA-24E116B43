AI Assistance Report – Express + React Project
Purpose
This document summarizes the areas where AI assistance was used during the development of my
Express.js and React application. AI was used as a learning and productivity tool to understand
concepts, debug issues, and accelerate implementation. All code was reviewed, integrated, tested,
and modified as required before being included in the project.
1. Backend–Frontend Integration
AI was used to understand how to connect an Express backend with a React (Vite) frontend.
Guidance included: Installing and configuring the cors middleware. Creating a reusable api.js file
using Axios. Using environment variables (.env) with VITE_API_URL. Sending GET, POST, PUT,
and DELETE requests from React. Organizing frontend and backend folder structures. Explaining
request/response flow between React, Express, and PostgreSQL.
2. Returning User Data as an Array
AI helped implement and understand backend endpoints that return user data as arrays. Assistance
included: Writing Express route handlers. Using PostgreSQL queries to fetch all users. Returning
structured JSON responses. Understanding how React receives and renders array data using
map().
3. Bonus Task Assistance
AI provided support in completing the bonus task by: Explaining the required implementation
approach. Suggesting backend logic and API design. Helping debug errors encountered during
implementation. Providing example code snippets that were adapted for the final solution.
4. Form.jsx Development
AI was used for minor assistance while building the React Form.jsx component: Managing
component state using useState. Creating controlled input fields. Submitting form data using Axios.
Basic validation and error handling. Adjusting the form to support the bonus task requirements.
5. Additional Learning and Debugging
Throughout development, AI also assisted with: Understanding Express routing and middleware.
Debugging CORS and server connection issues. Resolving PostgreSQL query errors.
Understanding HTTP methods and status codes. Explaining Axios usage and asynchronous
requests. Improving overall project structure and code organization.
Conclusion
AI served as a development assistant rather than a replacement for implementation. It was primarily
used to explain concepts, provide example code, troubleshoot errors, and suggest improvements.
The final integration, testing, debugging, and project assembly were completed as part of the
development process
